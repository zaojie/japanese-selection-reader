# 日语朗读

选中文字，右键选择 **用日语朗读选中文字**。再次朗读会打断上一段；点击工具栏中的扩展图标，可查看日语语音状态、错误提示或停止朗读。

## 本地安装（Chrome / Edge）

先从 [最新发布版](https://github.com/zaojie/japanese-selection-reader/releases/latest) 下载 `japanese-selection-reader.zip` 并解压，保留解压后的文件夹。

1. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择解压后的插件文件夹（直接包含 `manifest.json`）。安装后不要移动或删除该文件夹。
4. 建议在浏览器扩展菜单中将「日语朗读」固定到工具栏。
5. 在普通网页选中 `こんにちは。日本語を勉強しています。`，右键选择朗读菜单。

无需 npm 安装、构建、账号或 API 密钥。当前针对 Chrome / Edge，未提供 Firefox / Safari 版本。

## 配合在线试卷学习

可以在 [OK JLPT 在线练习](https://okjlpt.com/zh-Hans/try/e40d5afd-a7d3-4a5b-b9dc-bf4d6d3ce66d) 中选中日语原文，通过右键朗读辅助跟读；遇到意思不明的段落，可按需使用 [沉浸式翻译](https://immersivetranslate.com/zh-Hans/) 查看中文对照。两者为独立第三方产品，本扩展未与其进行接口集成。

建议顺序：先读原题 → 不会读时听读、跟读 → 尝试作答 → 必要时查看翻译 → 对照答案复盘。初学者从适合自己水平的材料开始；模拟考试时关闭听读和翻译辅助。合成语音可能读错多音汉字和人名，不能替代听力题原始音频或权威读音资料。

## 没有声音

打开扩展面板查看是否发现日语语音；朗读失败时工具栏显示 `!`，具体原因显示在扩展面板中。

- macOS：在系统设置中搜索「朗读与语音」（旧版本为「朗读内容」），在系统声音的管理界面下载日语声音。
- Windows：在设置中搜索「语音设置」，添加日语语音。
- 下载后重启浏览器，再打开扩展面板检查。最终以浏览器实际提供的语音为准。

第一版只使用浏览器报告为本机的日语语音；缺少语音时会提示安装，不回退到其他语言或远程语音。所有选中文字都按日语读，暂不自动识别语言，也不翻译。每次最多 32,768 个 UTF-16 代码单元，超长请分段选择。

仅能处理浏览器原生可选中的文字。图片文字、部分自绘网页和特殊 PDF 查看器可能没有原生选区或扩展右键菜单。

## 权限与隐私

- `contextMenus`：在文字选区的右键菜单加入朗读入口。
- `tts`：查询和调用浏览器语音接口。

不申请网页访问、剪贴板、历史记录或存储权限，不保存选中文字，不发起网络请求。调用时绑定本机日语语音；第三方语音引擎的本地/远程标记由引擎提供。

实现依据：[Chrome TTS API](https://developer.chrome.com/docs/extensions/reference/api/tts)、[右键菜单 API](https://developer.chrome.com/docs/extensions/reference/api/contextMenus)。

## 开发检查

使用 Node.js 22 或更新版本执行 `npm test`。测试覆盖语音筛选、输入边界、右键朗读、替换朗读、停止及错误处理。浏览器 API 使用模拟对象；实际发声需安装扩展后人工验证。
